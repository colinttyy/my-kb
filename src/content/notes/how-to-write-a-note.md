## 三步发布一篇笔记

### 第一步：新建文件

在 `src/content/notes/` 文件夹里，新建一个文本文件，**文件名用英文或拼音**。

比如你想写《CDU 冷量怎么算》，就建：

```text
src/content/notes/cdu-cooling-capacity.md
```

文件名会变成网址：`你的域名/notes/cdu-cooling-capacity/`

> 文件名别用中文、别用空格、别用特殊符号，否则网址会变成乱码。

### 第二步：复制这段开头，改掉里面的内容

文件最上面必须有 `---` 包起来的一段"信息头"，这是网站读取标题和日期的依据：

```markdown
---
title: CDU 冷量怎么算
description: 一句话说清这篇讲什么，会显示在列表和搜索结果里
date: 2025-11-25
tags: [CDU, 液冷, 计算]
---

正文从这里开始写。
```

**几个必须注意的点：**

- `---` 必须**各占一行**，成对出现，不能写成 `--` 或 `----`
- `date` 的格式必须是 `2025-11-25`，不能写 `2025年11月25日`
- `tags` 用方括号，多个标签用英文逗号隔开
- `description` 不是必填，但**强烈建议写**，否则列表里只有标题，没人想点

### 第三步：保存，看效果

- 如果 `开始写.bat` 的窗口还开着：存盘后浏览器**自动刷新**，不用做别的。
- 如果窗口关了：双击 `开始写.bat` 重新打开。

## 正文能用哪些写法

### 二级标题、三级标题

用 `##` 开头是二级标题（会自动加横线），`###` 是三级标题。**长文一定要分标题**，不然没人读得下去。

### 加粗、斜体、行内代码

`**这是加粗**` → **这是加粗**，用来标重点。
`这是行内代码` 用反引号包起来，适合写参数名、文件名。

### 列表

```markdown
- 第一项
- 第二项
  - 缩进两个空格就是子项

1. 有序列表第一项
2. 第二项
```

### 表格

```markdown
| 参数 | 含义 | 常见取值 |
|---|---|---|
| 冷量 | 单位时间带走的热量 | kW |
| ΔT | 进出水温差 | 5–10℃ |
```

效果：

| 参数 | 含义 | 常见取值 |
|---|---|---|
| 冷量 | 单位时间带走的热量 | kW |
| ΔT | 进出水温差 | 5–10℃ |

### 引用

> 用 `>` 开头。适合放结论、别人的原话、或者"注意"这类提示。

### 代码块

三个反引号包起来，适合放公式、命令行：

```text
Q = V̇ · ρ · c_p · ΔT
```

### 链接和图片

```markdown
[文字](https://example.com)
![图片说明](/images/文件名.png)
```

图片要先放进 `public/images/` 文件夹，然后用 `/images/文件名.png` 引用。

## 我自己的写作习惯（供参考）

1. **先写结论**，再写推导。读者只想知道"该怎么做"，不关心你怎么想到的。
2. **标题写具体**，别写"关于液冷的一些思考"，写"单柜 15kW 以上为什么该上冷板"。
3. **数字留着**，比形容词有说服力。
4. **不确定的就标注"待验证"**，比装作确定更可信。
